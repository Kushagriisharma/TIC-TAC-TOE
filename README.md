# Tic Tac Toe - Premium Edition

A premium, interactive, and modern web version of the classic Tic-Tac-Toe board game, built using vanilla HTML5, CSS3, and ES6 JavaScript. It features an unbeatable AI opponent powered by the Minimax recursion algorithm.

---

## 🚀 Key Features

* **Dual Game Modes:** Play Player vs Player (local multiplayer) or Player vs AI (singleplayer).
* **Unbeatable AI (Minimax):** The computer player analyzes every possible game outcome dynamically to play perfect defense and offense. It is impossible to beat!
* **Modern Premium Styling:** Designed with radial gradients, glassmorphism card containers, glowing neon colors for X (pink) and O (cyan), and smooth hover scale feedback.
* **Winner Alert Overlay:** Triggers a clean screen-blur overlay modal when a match results in a win or draw.
* **Responsive Layout:** Designed mobile-first and scales beautifully on small smartphones up to standard desktops.
